# Cyber Security Task 1 — Website Vulnerability Assessment

- Website assessed: https://wellnessdiagnosticcenter.in/
- Scope: Public-facing pages; read-only manual browsing and passive ZAP scan
- Tools: Firefox, OWASP ZAP 2.17.0
- Testing limits: No login testing, exploitation, brute force, DoS, or active scan. Nmap was not run.
- Files: Assessment report PDF and supporting screenshots are included in this repository.
